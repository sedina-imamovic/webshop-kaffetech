# Kaffetech – Online Coffee Shop

## About the Project

Kaffetech is a webshop project focused on coffee products. The website is built in Swedish and was developed as part of my studies.

The project gave me practical experience in building a website using HTML, CSS, and JavaScript.

## Features

* Browse coffee products and view product information
* Add products to the shopping cart
* Navigate between different pages
* Styled user interface using CSS
* Responsive design for mobile devices
* Keyboard navigation and usability
* Product data stored in JSON format

## Technologies Used

* HTML5
* CSS3
* JavaScript
* JSON

## Language

The website's content and user interface are in Swedish. This README is written in English to make the project easier to understand for an international audience.

## Live Demo

## Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/sedina-imamovic/webshop-kaffetech.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.
